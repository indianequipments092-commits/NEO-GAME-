# NEON SPACE SURVIVAL

A fast-paced space survival roguelite game.

## Development

This repository is the base project for **NEON SPACE SURVIVAL**. Development is organized into 11 phases, starting with GitHub/project setup and progressing through core gameplay, combat, progression, content, ships and modules, polish, and final release preparation.

## Current Phase

**Phase 1 — GitHub Base & Project Setup**

Phase 1 establishes the repository foundation and keeps generated Godot/build files out of version control.

## Repository

- Default branch: `main`
